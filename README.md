# dependabot-pnpm-versions-repro

Minimal projects for checking that Dependabot can update pnpm repositories at different pnpm versions
(dependabot/dependabot-core#13874). Each `pnpm-<version>` branch pins `packageManager` to that pnpm release,
has a lockfile generated by that release, and contains two outdated direct dependencies (`etag`, `is-odd`).
